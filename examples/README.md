# Examples

Two complete deliverables, generated by the kits in this repository, so reviewers can judge output quality without installing anything.

The company used in both examples — **Clínica Dental Sonrisa Norte**, a dental clinic in Ruzafa, Valencia — is fictional. Every figure, review, price and metric is synthetic. No real business or person is represented.

---

## 1. Business audit report — `kit-auditoria-negocio`

| File | Format | Description |
|---|---|---|
| [`auditoria-negocio-clinica-sonrisa-norte.html`](./auditoria-negocio-clinica-sonrisa-norte.html) | Self-contained HTML | Interactive report: score rings, animated bars, sticky navigation |
| [`auditoria-negocio-clinica-sonrisa-norte.pdf`](./auditoria-negocio-clinica-sonrisa-norte.pdf) | PDF, A4 | Print export of the same report, generated with headless Chrome |

**Input given to the skill:** business name, sector, city, website, Instagram handle, services and prices, active ads, two competitors.

**Output structure** (the contract defined in the skill):

1. Global score (58/100) with a twelve-area breakdown.
2. Executive summary: current state, root cause, opportunity.
3. Seven inconsistencies and errors, each with severity, why it matters and a concrete fix.
4. Customer journey map, marking the two phases that do not exist.
5. Per-area detail: what works, what does not, next actions.
6. Copy analysis with before/after rewrites.
7. Prioritised action plan (impact × effort).
8. Five quick wins for the current week.
9. Competitor comparison.

**What to look at:** the findings are specific and falsifiable ("three different prices for the first visit"), not generic advice. The report never invents data it was not given; where information is missing, it says so.

To regenerate the PDF:

```bash
chrome --headless --no-pdf-header-footer \
  --print-to-pdf=auditoria-negocio-clinica-sonrisa-norte.pdf \
  auditoria-negocio-clinica-sonrisa-norte.html
```

## 2. Landing page — `kit-web-scrolling`

| File | Format | Description |
|---|---|---|
| [`web-clinica-sonrisa-norte.html`](./web-clinica-sonrisa-norte.html) | Single HTML file | Full landing page, inline CSS and JS, Google Fonts only |

**Sections:** sticky navigation with blur on scroll, hero with parallax blobs, about with animated counters, six treatment cards with prices, gallery placeholders, pull quote, three testimonials, contact form and footer.

**Implementation notes:**

- Reveals, stagger and counters use the native `IntersectionObserver`; no animation library.
- Parallax runs in a single `requestAnimationFrame` loop with a passive scroll listener.
- `prefers-reduced-motion` disables all motion and reveals content immediately.
- Light clinical palette on purpose: the skill switches theme by sector, and clinics are explicitly a light-theme case.
- Photo slots are labelled `[FOTO REAL DEL EQUIPO]` — the skill never substitutes stock imagery for a business's own photos.

**What to look at:** scroll behaviour, mobile navigation, and the print stylesheet (the same file prints cleanly).

## Regenerating these examples

Both files were produced by opening the corresponding kit folder in Claude Code and describing the business. Nothing was hand-edited after generation except the fictional data itself.

```bash
cd ../kits/kit-auditoria-negocio
claude
# "Audita mi negocio digital: Clínica Dental Sonrisa Norte, Valencia…"
```

The banner and preview images in [`../assets`](../assets) were captured from these files with headless Chrome at 1280–1440 px width.
